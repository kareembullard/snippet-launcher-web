#  Shortcuts and Hot Keys 121124
    
##  Amplenote Shortcuts
    
###  Navigation
    - Ctrl + O: Quick open dialog
    - Ctrl + Shift + ,: Return to previous note
    - `[[` followed by the note name: Link to a note
    - `[`: Turn selected text into a note link or create a new note
    - `[[=`: Copy content from another note
    - `#`: Link to a section in that note
    
###  Tasks
    - `[]` followed by space: Create a task
    - Ctrl + Space: Complete a task
    - Ctrl + .: Open/Close task details
    - Alt + Shift + U: Mark a task as Urgent
    - Alt + Shift + I: Mark a task as Important
    - `!`: Open task commands
    
###  Formatting
    - Ctrl + K: Add a link or rich footnote
    - Ctrl + ,: Expand or collapse sub-bullets

##  Linux Shortcuts
    
###  Terminal Shortcuts
    - Ctrl + Alt + T: Open a new terminal
    - Ctrl + L: Clear the terminal screen
    - Ctrl + C: Kill the current process
    - Ctrl + Z: Suspend the current process
    - Ctrl + R: Search command history
    - Up/Down Arrow: Scroll through command history
    - Tab: Auto-complete commands or file names
    
####  Text Navigation
    - Ctrl + A: Move to the beginning of the line
    - Ctrl + E: Move to the end of the line
    - Ctrl + U: Cut everything before the cursor
    - Ctrl + K: Cut everything after the cursor
    - Ctrl + W: Cut the word before the cursor
    - Ctrl + Y: Paste the last cut text
    
####  Command Shortcuts
    - !!: Repeat the last command
    - !n: Run command number n from history
    - !string: Run the most recent command that starts with string
    
##  File and Directory Management
    - cd ~: Navigate to the home directory
    - cd -: Navigate to the previous directory
    - ls -l: List files in long format
    - ls -a: Show hidden files
    - mkdir dirname: Create a new directory
    - rm -r dirname: Remove a directory and its contents
    - cp source dest: Copy files or directories
    - mv source dest: Move or rename files or directories
    - touch filename: Create an empty file
    
##  Text Editors (Nano and Vim)
    - Nano
      - Ctrl + O: Save file
      - Ctrl + X: Exit Nano
    - Vim
      - i: Enter insert mode
      - Esc + :wq: Save and quit
      - Esc + :q!: Quit without saving
    
##  System Monitoring
    - top: Display running processes
    - htop: Advanced process viewer
    - Ctrl + C: Exit top or htop
    - df -h: Show disk usage
    - free -h: Show memory usage
    - ps aux: Display all running processes
    - kill -9 PID: Force kill a process by PID
    
##  Networking
    - ping hostname: Check network connectivity
    - ifconfig: Display network interfaces
    - ip a: Show IP addresses
    - netstat -tuln: Show active connections
    - ssh user@hostname: Connect to a remote server via SSH
    - scp file user@hostname:/path: Securely copy files to a remote server
    - wget URL: Download files from the web
    
##  Package Management (Debian/Ubuntu)
    - apt update: Update package list
    - apt upgrade: Upgrade installed packages
    - apt install package: Install a package
    - apt remove package: Remove a package
    - apt autoremove: Remove unnecessary packages
    
##  File Viewing
    - cat filename: View file contents
    - less filename: View file contents page by page
    - head -n N filename: View the first N lines of a file
    - tail -n N filename: View the last N lines of a file
    - grep 'string' filename: Search for a string in a file
    
##  System Navigation
    - Ctrl + Alt + Arrow (Left/Right): Switch between virtual desktops
    - Alt + Tab: Switch between open windows
    - Ctrl + Alt + Backspace: Restart the X server (graphical environment)
    
##  Advanced Utilities
    - chmod permissions filename: Change file permissions
    - chown user:group filename: Change file ownership
    - find /path -name filename: Search for files by name
    - tar -czvf archive.tar.gz foldername: Compress a folder
    - tar -xzvf archive.tar.gz: Extract a compressed archive
